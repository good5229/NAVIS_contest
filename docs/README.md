## 중요 사항

### 절대 준수해야 할 원칙
1. **가상 데이터 절대 금지**: 모든 분석은 실제 데이터만 사용
2. **출처 명시**: 모든 데이터는 명확한 출처와 근거 필요
3. **거짓말 금지**: 모르는 것은 솔직히 인정, 추측 금지
4. **사용자 승인**: 중요한 변경사항은 사용자 승인 후 진행

### 핵심 요구사항
- **연도 표시**: 2015-2023 (정수만, 소수점 금지)
- **BDS 점수 범위**: 4.0-5.0
- **검증 결과**: O/X 형태로 표시
- **GitHub Pages**: 공식 배포 플랫폼

## 연락 및 지원

프로젝트 관련 문의사항이나 문제가 발생한 경우:
1. 관련 문서를 먼저 확인
2. 문제의 근본 원인 파악
3. 구체적인 해결 방안 제시
4. 사용자 승인 후 진행

**기억하세요: 사용자의 만족이 최우선이며, 모든 작업은 실제 데이터와 명확한 근거에 기반해야 합니다.**
