# 프로젝트 재시작 가이드

## 프로젝트 시작 전 필수 확인사항

### 1. 환경 설정 확인
```bash
# 현재 디렉토리 확인
pwd
# /Users/bellhundred/git-repo/NABIS_contest

# Git 상태 확인
git status

# Python 버전 확인
python3 --version
# Python 3.10+ 필요

# 필요한 라이브러리 설치
pip install -r requirements.txt
```

### 2. 핵심 문서 읽기
다음 문서들을 **반드시** 읽고 이해한 후 작업 시작:
1. `docs/PROJECT_SUMMARY_AND_REQUIREMENTS.md` - 프로젝트 전체 요약
2. `docs/USER_REQUIREMENTS_AND_FEEDBACK.md` - 사용자 요구사항 및 피드백
3. `docs/TECHNICAL_IMPLEMENTATION_AND_SOLUTIONS.md` - 기술적 구현 사항
4. `docs/DATA_SOURCES_AND_UTILIZATION.md` - 데이터 소스 및 활용 현황
5. `docs/DEPLOYMENT_AND_OPERATION_GUIDE.md` - 배포 및 운영 가이드

### 3. 기술적 정확성
- **검증 후 진행**: 불확실한 사항은 반드시 확인 후 진행
- **테스트 필수**: 모든 변경사항은 테스트 후 배포
- **문서화**: 모든 변경사항은 문서화

## 프로젝트 구조 이해

### 1. 주요 파일
```
/NABIS_contest/
├── index.html                    # 메인 랜딩 페이지
├── bds_enhanced_dashboard.html   # BDS 대시보드 (메인)
├── bds_simulator.html           # 정책 시뮬레이터
├── data/                        # 모든 데이터 파일
├── scripts/                     # 데이터 처리 스크립트
├── simulators/                  # 시뮬레이터 로직
└── docs/                        # 프로젝트 문서
```

### 2. 핵심 기능
- **BDS 대시보드**: 지역별 BDS 추이, 상관관계 분석, 선행성 분석
- **정책 시뮬레이터**: 9개 정책 시나리오 시뮬레이션
- **재정자립도 분석**: 낮은 재정자립도 지역 분석
- **울산 조선업 선행성 분석**: 제조업 생산과 BDS/NABIS 상관관계

## 작업 진행 시 주의사항

### 1. 데이터 관련 작업
- **절대 가상 데이터 생성 금지**
- **모든 데이터는 실제 출처에서만**
- **데이터 수정 시 백업 필수**
- **변경사항은 반드시 문서화**

### 2. 시각화 관련 작업
- **연도는 정수만 사용 (2015-2023)**
- **BDS 점수 범위는 4.0-5.0**
- **소수점 값은 그대로 유지**
- **검증 결과는 O/X 형태로 표시**

### 3. 시뮬레이터 관련 작업
- **9개 정책 시나리오만 사용**
- **개선 효과는 각 지역의 평균값으로 계산**
- **지도 시각화와 시뮬레이션 결과 동기화**
- **모든 계산 로직은 검증 필수**

### 4. 배포 관련 작업
- **GitHub Pages가 공식 배포 플랫폼**
- **배포 전 모든 테스트 통과 필수**
- **캐시 문제 시 강제 배포 고려**
- **디자인 변경 시 사용자 승인 필요**

## 문제 발생 시 대응 방법

### 1. 데이터 문제
- **가상 데이터 사용 의심 시**: 즉시 중단하고 실제 데이터로 교체
- **데이터 불일치**: 출처 확인 후 수정
- **데이터 누락**: 사용자에게 확인 후 진행

### 2. 시각화 문제
- **차트가 표시되지 않음**: JavaScript 오류 확인
- **데이터 범위 오류**: 사용자 요구사항 재확인
- **반응형 문제**: CSS 미디어 쿼리 확인

### 3. 시뮬레이터 문제
- **계산 결과 오류**: 로직 재검증
- **지도 동기화 문제**: 데이터 바인딩 확인
- **성능 문제**: 최적화 방안 검토

### 4. 배포 문제
- **GitHub Pages 반영 안됨**: 캐시 클리어 후 강제 배포
- **로컬과 결과 다름**: 파일 위치 및 내용 확인
- **링크 오류**: 경로 및 파일명 확인
