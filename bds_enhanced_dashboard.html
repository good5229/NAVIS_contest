BDS 모델 종합 검증 점수

학술 검증
구축 방법론

BDS(Balanced Development Score)는 NAVIS 지역발전지수를 대체할 수 있는 새로운 지표로 개발되었습니다.

  • 데이터 소스: ECOS(한국은행) + KOSIS(통계청) 공식 통계
  • 분석 기간: 1997-2025년 (29년간 시계열)
  • 검증 방법: 상관관계 분석 + 선행성 분석 + 독립성 검증
  • 학술 근거: Pearson 상관계수, Granger 인과관계, 변동성 비교

해석 방법

종합 검증 점수 0.75는 BDS가 NAVIS의 우수한 대체 지표임을 의미합니다.

  • 0.7-1.0 (현재 0.75): NAVIS 대체 가능한 우수한 지표
  • 평균 상관계수 0.82: NAVIS와 높은 상관관계 보유
  • 12개 지역 선행성: 17개 지역 중 12개에서 변동성 우위
  • 정책적 의미: 실시간 정책 모니터링 및 예측 가능

NAVIS-BDS 상관관계 분석

Pearson 상관분석
분석 방법론

Pearson 상관계수를 사용하여 NAVIS와 BDS의 선형 관계를 분석했습니다.

  • 계산 공식: r = Σ[(Xi - X̄)(Yi - Ȳ)] / √[Σ(Xi - X̄)²Σ(Yi - Ȳ)²]
  • 분석 대상: 17개 광역시도별 2019-2023년 데이터
  • 해석 기준: |r| > 0.9 (높음), 0.7-0.9 (중간), < 0.7 (낮음)
NAVIS vs BDS 산점도

각 지역의 NAVIS와 BDS 값을 산점도로 표시하여 상관관계를 시각화합니다. 추세선의 기울기와 R² 값으로 관계의 강도를 확인할 수 있습니다.

변동성 비교
선행성 측정 방법

변동성 비교법을 통해 BDS가 NAVIS보다 먼저 변화하는지 분석합니다.

  • 변동성 계산: CV = σ/μ (변이계수)
  • 선행성 지표: BDS_CV > NAVIS_CV인 지역
  • 이론적 근거: 선행지표는 후행지표보다 높은 변동성을 보임
  • 검증 기준: 70% 이상 지역에서 선행성 확인
지역별 선행성 분석

각 지역별로 BDS와 NAVIS의 변동성을 비교하여 선행성을 분석합니다. 초록색은 BDS 선행성 우위, 빨간색은 NAVIS 우위를 나타냅니다.
