BDS 모델 종합 검증 점수

학술 검증
구축 방법론

BDS(Balanced Development Score)는 EU RCI 방식을 적용한 한국형 지역균형발전지수입니다.

  • 데이터 소스: ECOS(한국은행) + KOSIS(통계청) 공식 통계
    • EU RCI 방식 차등 가중치 적용
    • 지역별 1인당 GRDP 기준 3단계 분류 (고/중/저소득)
  • 분석 기간: 2020-2024년 (5년간, 모든 지표 완전 가용)
  • 방법론: EU Regional Competitiveness Index 기반 한국형 지역균형발전 가중치
  • 데이터 완전성: GRDP, 재정자립도, 제조업/서비스업 생산지수 모두 포함
  • 검증 방법: 상관관계 분석 + 선행성 분석 + 독립성 검증
  • 학술 근거: Pearson 상관계수, Granger 인과관계, 변동성 비교

Pearson 상관분석
분석 방법론

Pearson 상관계수를 사용하여 BDS 구성지표들 간의 선형 관계를 분석했습니다.

  • 계산 공식: r = Σ[(Xi - X̄)(Yi - Ȳ)] / √[Σ(Xi - X̄)²Σ(Yi - Ȳ)²]
  • 분석 대상: 17개 광역시도별 2019-2023년 데이터
  • 해석 기준: |r| > 0.9 (높음), 0.7-0.9 (중간), < 0.7 (낮음)
